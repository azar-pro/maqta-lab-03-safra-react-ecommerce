# MAQTA Lab 03 — SAFRA React E-commerce

SAFRA is a fictional contemporary accessories boutique built as a React e-commerce learning and portfolio project.

## Stack
- React
- Vite
- React Router
- CSS
- localStorage for cart and wishlist persistence

## Current features
- Responsive home page
- Product catalog
- Search, category filters and sorting
- Dynamic product detail pages
- Product color selection
- Persistent shopping cart
- Quantity controls and subtotal calculation
- Wishlist persistence
- Free-shipping threshold logic
- Demo checkout with client-side validation
- Empty states and 404 states
- Mobile navigation
- MAQTA Studio creator credit

## Run locally
1. Install Node.js LTS if it is not installed.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown by Vite, normally `http://localhost:5173`.

## Important
This is a fictional portfolio store. No payment gateway, order API, database or real customer-data collection is connected.
